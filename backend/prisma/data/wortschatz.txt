# Központi szókincs (A1–B1) – a `prisma/import-vocabulary.ts` formátumában.
#
# Soronként egy szó, mezőelválasztó: |   Többértékű mező: ; (fordítások) , (kategóriák)
# Üres sor és # kezdetű sor: megjegyzés.
#
# Főnév:     N|szint|névelő|alak|többes szám|fordítások|kategóriák|példa|jelzők
#              névelő: der / die / das, csak többes számú főnévnél: pl
#              többes szám: - = csak egyes számú (Singularetantum)
#              jelzők: n = gyenge (n-)deklináció
# Ige:       V|szint|alak|E/3 jelen|E/3 Präteritum|segédige + Partizip II|típus|fordítások|kategóriák|példa|vonzat
#              alak: elváló igekötő ·-tal (an·kommen), visszaható: „sich ” / „sich(D) ” előtag
#              típus: r = gyenge, i = erős, m = vegyes
# Melléknév: A|szint|alak|középfok|felsőfok|fordítások|kategóriák|példa|jelzők
#              nem fokozható: - -   jelzők: ! = rendhagyó fokozás, p = csak állítmányi
# Egyéb:     X|szint|szófaj|alak|fordítások|kategóriák|példa
#
# példa:  német mondat = magyar fordítás
# vonzat: elöljáró:eset:jelentés  (eset: A = Akk., D = Dat., G = Gen.; elöljáró nélkül: -)
# =============================================================================
